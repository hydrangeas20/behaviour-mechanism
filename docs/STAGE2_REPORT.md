# Stage 2 technical report: exploratory E2 experiment

**Status:** exploratory. One seed per configuration. Nothing here is a pre-registered or
confirmatory result, and the eight-seed study has not been started. Runs and decision
rules were written down before training in [STAGE2_PROTOCOL.md](STAGE2_PROTOCOL.md), which
also records two amendments made during the runs.

All numbers come from `results/stage2/` and are regenerated by the commands in §11.

## 1. Research question

Can measurement artifacts produce an apparent delay between behavioural competence and
mechanistic emergence?

Two readings of any apparent delay are compared:

- **Artifact:** the delay comes from the defined fraction (what the model outputs on the
  probe inputs), from the choice of corruption or site, or from the summary rule.
- **Developmental:** the causal profile, conditional on a defined gap, keeps changing after
  behaviour has stabilised, and does so under several corruptions.

## 2. The original measurement problem

The original experiment reported that a patching statistic stabilised 1,700–2,200 steps
after accuracy. The audit found that the task was solvable by fixed-offset copying and that
the statistic mostly counted probe pairs with a defined output gap. Stage 1 added a third
problem: the statistic patches attention outputs only, so it reads 0 on a hand-built copier
whose gate runs through an MLP, even with every pair defined
([METRIC_METHODOLOGY.md](METRIC_METHODOLOGY.md) §1).

## 3. Corrected methodology

`bm-patch-2` (`measurement.py`) reports, for each site, direction and corruption: attempted,
defined and undefined pairs; the defined fraction; and the effect conditional on defined
pairs (`None` when none is defined). The legacy statistic is kept beside it as
`legacy_patch_effect_size_v1`.

Positive controls:

| Control | Cells matching the hand-derived prediction |
|---|---|
| Fixed-offset copiers: ungated, MLP-gated, attention-gated (`results/stage1/positive_controls/`) | 192 / 192 |
| Two-layer induction model, distinct-token pairs (`results/stage2/calibration/`) | 80 / 80 (largest error 0.003) |
| Same model, natural pairs with chance duplicate tokens | effects within 0.036 of prediction; 97.7–100% of pairs defined |

The induction control gives a reference signature for E2 pairs:

| Corruption | Early (previous-token) attention | Late (induction) attention | Residual after layer 0 at the read position |
|---|---|---|---|
| earlier occurrence | 1 | 1 | 0 |
| copy source | 0 | 1 | 0 |
| query token | 0 | 1 | 1 |

## 4. E2 task construction

Generator `e2-v1` (`e2.py`). Vocabulary 100, length 64.

- **Sequences.** 70% are repeat sequences: a chunk of length L at start s is repeated
  immediately (`tokens[s+L : s+2L] = tokens[s : s+L]`). The rest are uniformly random.
- **Randomisation.** L is uniform over 8–24 **except 11, 17 and 22**, which are held out
  of training. s is uniform over the positions that fit. The offset (= L) and the absolute
  position both vary per sequence.
- **Labels.** Next-token prediction. Scored targets are `s+L+1 … s+2L−1`; the first
  repeated token is excluded because token matching cannot predict it. Scored positions are
  up-weighted ×3 in the loss, as in the original objective.
- **Splits.** Separate RNG streams for training, validation and test. Validation is used
  for monitoring during training; every number in this report uses the test stream.
- **Leakage controls** (`results/stage2/baselines/leakage.json`): of 12,000 evaluation
  sequences, none appears among the 512,000 training sequences, and no chunk is shared;
  held-out lengths never occur in training; no training sequence is duplicated.
- **Difficulty.** Tokens are drawn with replacement, so the current token often has more
  than one earlier occurrence. Single-token matching is ambiguous then (§5).
- **Expected behaviour.** A token-matching model should score near the reference
  solution on trained, held-out and extrapolated lengths alike.
- **Remaining shortcuts.** The repeat is adjacent, so a model can learn a *mixture of
  positional copiers*, choosing the likeliest offset for each position. §5 measures it.
  The held-out lengths, extrapolation lengths (4, 5, 6, 28, 30, 32) and non-adjacent
  "gap" probes exist to detect it.

Departures from the roadmap's E2 sketch: the held-out lengths are an addition; the
two-layer attention-only variant, the no-repeat negative control and attention-score
measurements were not done.

lengths.

## 7. Exploratory results

### 7.1 Observations: behaviour

Test accuracy on scored positions (`behaviour.jsonl`):

| Step | Primary: trained / held-out | Secondary: trained / held-out | Secondary: extrapolation | Secondary: gap 8 |
|---|---|---|---|---|
| 1,000 | 0.100 / 0.068 | 0.130 / 0.033 | 0.013 | 0.061 |
| 4,000 | 0.171 / 0.056 | 0.214 / 0.049 | 0.015 | 0.086 |
| 4,250 | — | 0.305 / 0.113 | 0.034 | 0.109 |
| 4,500 | — | 0.872 / 0.851 | 0.499 | 0.655 |
| 4,750 | — | 0.954 / 0.952 | 0.760 | 0.864 |
| 5,500 | — | 0.981 / 0.980 | 0.868 | 0.930 |
| 8,000 | **0.212 / 0.070** | **0.992 / 0.991** | 0.892 | 0.944 |

- **The primary run did not learn the task.** It ended at 0.212 on trained lengths and
  0.070 on held-out lengths. By the rule fixed in advance (final accuracy ≥ 0.90), this is
  a failure to learn.
- **The secondary run learned it**, between steps 4,250 and 4,500, after about 4,000 steps
  on the same plateau. Its final accuracy equals reference B (0.992).
- The secondary run's accuracy by chunk length at step 8,000 is 0.969–0.998 for every
  trained length, 0.985–0.994 for the held-out lengths, and 0.83–0.95 for extrapolation
  lengths (lowest at 32).
- On shuffled repeats it scores 0.067, and it outputs the in-order token 8% of the time.
- The first target inside a repeat is the hardest: 0.41 at step 4,500, 0.74 at 5,000, 0.88
  at 6,000, 0.92 at 8,000. Deeper targets are at 0.96–0.99 by step 5,000.
- The contingency run was still on the plateau when stopped (0.16 at step 4,750).

### 7.3 Interpretations

1. **Measurement choices alone move the apparent "lag" from −4,250 to +2,750 steps in
   this run.** Read with the original pipeline (legacy statistic ≥ 0.8), mechanism appears
   2,750 steps *after* behaviour under the original corruption's analogue, 250 steps
   *before* it under earlier-occurrence, and 4,250 steps before it under copy-source. The
   model and checkpoints are the same in all three. This supports the artifact reading
   for the legacy pipeline.
2. **The legacy statistic can be at ceiling without competence.** In the primary run it
   is 0.94–1.01 for 7,000 steps in a model with 0.21 accuracy that never learns the task.
   What it detects there is the positional copy pathway through layer-0 attention.
3. **The plateau is consistent with the positional-mixture shortcut,** not induction:
   accuracy on trained lengths (0.10–0.21 from step 1,000) sits near the shortcut's level
   (0.136), held-out lengths stay at 0.02–0.07, and all mediation is in layer 0. This is an
   inference from behaviour and patching; the internal computation was not examined
   directly.
4. **The transition is a change of mechanism as far as this measurement can see.**
   Between steps 4,250 and 4,500, mediation moves from layer-0 attention to layers 1 and 3,
   and accuracy on held-out lengths jumps from 0.11 to 0.85. The pattern after the
   transition resembles the two-stage signature of the constructed induction model (an
   earlier layer that matters for the earlier occurrence, a later layer that matters for
   everything), with deviations: layer-1 denoising under copy-source is 0.30, not 0, and
   layer-3 MLPs are involved. That is consistent with an induction-like computation. It
   does not establish one.
5. **Behaviour and the causal profile change in the same 250-step interval.** No lag
   between them is resolved at this checkpoint spacing.
6. **Slow drift after the transition is seen in both kinds of measurement.** Some
   conditional effects settle at 6,500–6,750, later than accuracy on trained lengths
   (4,750). Yet the hardest behavioural slice, the first target in a repeat, also keeps
   improving until about 6,000. With one seed, a tolerance chosen after the fact and a
   250-step grid, a gap of 500–750 steps is not evidence of a developmental lag.

## 8. Failure analysis

| Question | Finding |
|---|---|
| Does the model learn the intended task? | Secondary run: yes by behaviour (0.992; held-out 0.991; gap probes 0.94–0.99; shuffled control 0.07). Primary run: no. |
| Do fixed-offset shortcuts remain? | The historical one does not (0.009). A positional mixture remains in the task; both runs sat on it for thousands of steps and the primary never left. In the secondary run it is gone after the transition, as far as held-out and gap probes can tell; extrapolation to L = 32 is weaker (0.83). |
| Are intervention effects stable? | On the plateau: yes for layer-0 attention under copy-source (0.94–1.01). After the transition: layer-3 attention effects are stable from about step 5,000; layer-1 attention and layer-3 MLP effects drift until 6,500–6,750. |
| Does the defined fraction change with training? | Yes. Earlier-occurrence rises from 0.56–0.84 on the plateau to 1.00, reaching 0.95 at step 4,250. On the plateau it reflects the positional mixture putting some probability on a neighbouring offset, not token matching. |
| Does conditional recovery change independently? | Partly. At the transition it changes together with behaviour. Afterwards a few cells drift while trained-length accuracy is flat, but a harder behavioural slice drifts over the same period. |
| Do conclusions depend on checkpoint choice? | Yes. Any comparison made at steps 500–4,000 would report a "mechanism" (legacy 0.95–1.00, copy source) without the behaviour. The transition falls inside one 250-step interval. |
| Does behaviour vary by difficulty? | Yes: by depth inside the repeat (first target 0.92 against ≥ 0.995 for deeper ones) and by extrapolated length. |

Negative and inconclusive results: the primary declared run failed to learn the task; the
contingency run is incomplete; the developmental reading is neither supported nor excluded;
`mlp_out.L0` effects near 1 under every corruption are uninformative, because patching an
MLP output at all positions restores the changed token itself.

## 9. Threats to validity

- **One seed per configuration.** The learning-rate difference between the declared runs
  is confounded with run-to-run variation. Whether the primary configuration can learn the
  task with more steps or another seed is unknown.
- **Outcome-informed steps.** The contingency run and its stopping were decided while
  watching the runs. The settling tolerance (0.05) and the thresholds (0.8, 0.9, 0.95)
  were chosen after seeing the data.
- **Checkpoint grid.** 250 steps. The transition is unresolved.
- **Corruptions and sites.** Four corruptions; attention, head, MLP and residual sites.
  Attention, head and MLP sites are patched at all positions, which mixes "this component
  computes it" with "this component passes the changed token along".
- **Pairs.** 128 natural pairs per corruption, with chance duplicate tokens; no
  uncertainty intervals. Read positions are uniform inside the repeat, so most are deep
  positions where the task is easiest.
- **Task.** Adjacent repeats only in training; a positional-mixture shortcut exists.
  Synthetic uniform tokens.
- **Reproducibility.** Runs are deterministic functions of the seeds in code, but they
  were executed once. Bit-for-bit reproduction on other hardware is not expected and was
  not tested.
- **Mechanism claims.** Mediation at a site is not identification of a circuit. The
  resemblance to the constructed induction model is qualitative.

## 10. Verdict and next confirmatory experiment

**Does the current evidence support, contradict or fail to distinguish the hypotheses?**

- *For the legacy measurement pipeline:* the evidence **supports the artifact reading**.
  The size and sign of the apparent lag are set by the corruption and threshold, and the
  statistic reaches ceiling in a model that never learns the task. This is one seed, so it
  is a demonstration that artifacts *can* produce the delay, not an estimate of how often
  they do.
- *For a genuine developmental lag on an induction-requiring task:* the evidence is
  **insufficient to distinguish**. No lag is resolved at the transition, and the slow
  drift afterwards appears in behaviour as well as in conditional effects.
- The original hypothesis (behaviour stabilises before mechanism) is **not supported** by
  anything here, and not refuted for induction either.

**Next confirmatory experiment (not started).** Pre-register and run E2 with 8 seeds:

1. Configuration: 4 layers, peak lr 1e-3, since the lr 3e-4 configuration did not learn
   the task in 8,000 steps. State this as an outcome-informed choice.
2. Checkpoints every 25 steps in a window around each seed's transition, located by a
   first pass at 250 steps.
3. Primary outcome: per seed, the difference between the step at which held-out accuracy
   settles and the step at which each pre-specified conditional effect settles, with
   tolerance and cells fixed in advance, and a pair bootstrap for within-checkpoint
   uncertainty.
4. Behavioural comparators must include the hardest slices (first target, extrapolation),
   not only overall accuracy.
5. Add the no-repeat negative control and a non-adjacent-repeat training variant that
   removes the positional mixture.

Estimated cost: about 45 min per seed on an idle 2-vCPU machine for training, plus about
20 min of evaluation; roughly 9 h for 8 seeds on CPU. GPU cost is not measured.

## 11. Reproduction

```sh
pip install -e ".[dev]"

# Figures and tables from the saved results (seconds):
bm e2-report            # figures/stage2/*.png, results/stage2/transitions.csv, settling_*.csv

# Controls, baselines and leakage checks (about 1 min each):
bm stage1-controls --out results/stage1/my_positive_controls
bm e2-calibrate    --out results/stage2/my_calibration
bm e2-baselines    --out results/stage2/my_baselines

# Training (about 45 min each on an idle 2-vCPU machine) and evaluation (about 20 min):
bm e2-train --seed 0 --out artifacts/e2/my_main
bm e2-train --seed 0 --lr 1e-3 --out artifacts/e2/my_lr1e-3
bm e2-eval --run artifacts/e2/my_lr1e-3 --out results/stage2/my_lr1e-3
```
